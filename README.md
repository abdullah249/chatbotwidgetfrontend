# Chatbot Widget Frontend

A React-based frontend for the Chatbot Widget application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Deployment

This project is configured for deployment on Vercel. The build command is automatically detected from the `package.json` file.

## Environment Variables

No environment variables are required for this project.
